1. JavaScript vs TypeScript vs Angular

Q: What is JavaScript?

JavaScript is a scripting language used mainly to make web pages dynamic and interactive. It runs in the browser and is used for DOM manipulation, event handling, API calls, validations, and client-side logic. 
let name = "Neelesh";
console.log(name);

Q: What is TypeScript?

TypeScript is a superset of JavaScript. It adds static typing, interfaces, classes, access modifiers, and better compile-time error checking. TypeScript code is compiled into JavaScript because browsers understand JavaScript, not TypeScript directly. 
let name: string = "Neelesh";
let age: number = 30;

interface User {
  id: number;
  name: string;
}

const user: User = {
  id: 1,
  name: "Neelesh"
};

Q: What is Angular?

Angular is a frontend framework used to build single-page applications. It is built using TypeScript and provides features like components, services, dependency injection, routing, forms, HTTP client, guards, and interceptors.

Q: Difference between JavaScript, TypeScript, and Angular?

JavaScript is the core scripting language used by browsers. TypeScript is a typed superset of JavaScript that helps us write better and safer code for large applications. Angular is a frontend framework built using TypeScript to develop single-page applications.

In simple words, JavaScript is the language, TypeScript improves JavaScript with typing and compile-time checks, and Angular provides the complete framework structure using TypeScript.

Browser finally runs JavaScript. TypeScript and Angular code are compiled and bundled into JavaScript during the build process.

3. JavaScript Basic Questions

Q: Difference between var, let, and const?

var is function-scoped, while let and const are block-scoped. let is used when value can change. const is used when reassignment is not required. In modern JavaScript, we prefer let and const instead of var. 
var a = 10;
let b = 20;
const c = 30;

b = 25; // allowed
// c = 35; // not allowed

Q: What is hoisting?

Hoisting means JavaScript moves variable and function declarations to the top of their scope during execution phase. var variables are hoisted with undefined, but let and const are hoisted in temporal dead zone and cannot be used before declaration. 
console.log(a); // undefined
var a = 10;

// console.log(b); // error
let b = 20;

Q: What is closure?

Closure means an inner function can access variables of its outer function even after the outer function has completed execution. Closures are useful for maintaining state and data hiding. 
function outer() {
  let count = 0;

  return function inner() {
    count++;
    return count;
  };
}

const counter = outer();
console.log(counter()); // 1
console.log(counter()); // 2

Q: Difference between == and ===?

== compares values after type conversion. === compares both value and type. In real projects, we prefer === to avoid unexpected type conversion. 
console.log(5 == "5");  // true
console.log(5 === "5"); // false

Q: What is this keyword?

this refers to the object that is currently executing the function. Its value depends on how the function is called. 
const user = {
  name: "Neelesh",
  showName: function () {
    console.log(this.name);
  }
};

user.showName(); // Neelesh

Q: Arrow function vs normal function?

Arrow functions provide shorter syntax and do not have their own this. They use this from the surrounding lexical scope. Normal functions have their own this depending on how they are called. 
const add = (a, b) => a + b;

function addNormal(a, b) {
  return a + b;
}

Q: What is spread operator?

Spread operator expands arrays or objects. It is useful for copying or merging arrays and objects. 
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];

const user = { name: "Neelesh" };
const updatedUser = { ...user, role: "Admin" };

Q: What is destructuring?

Destructuring is used to extract values from arrays or objects into variables. 
const user = { name: "Neelesh", role: "Admin" };
const { name, role } = user;

4. Callback, Promise, async/await

Q: What is callback function?

A callback is a function passed as an argument to another function and executed later. 
function greet(name, callback) {
  console.log("Hello " + name);
  callback();
}

greet("Neelesh", function () {
  console.log("Callback executed");
});

Q: What is Promise?

Promise is used to handle asynchronous operations. It can be in pending, fulfilled, or rejected state. 
const promise = new Promise((resolve, reject) => {
  let success = true;
  if (success) resolve("Data received");
  else reject("Error occurred");
});

promise
  .then(result => console.log(result))
  .catch(error => console.log(error));

Q: What is async/await?

async/await is a cleaner way to work with promises. await waits for promise completion without blocking the main thread. In frontend applications, async/await is commonly used for API calls. 
async function getData() {
  try {
    const response = await fetch("https://api.example.com/users");
    const data = await response.json();
    console.log(data);
  } catch (error) {
    console.log(error);
  }
}

5. Array Methods: map, filter, reduce

Q: What is map?

map transforms each item and returns a new array.
const nums = [1, 2, 3];
const squares = nums.map(x => x * x);
console.log(squares); // [1, 4, 9]

Q: What is filter?

filter returns items matching a condition.
const nums = [1, 2, 3, 4];
const even = nums.filter(x => x % 2 === 0);
console.log(even); // [2, 4]

Q: What is reduce?

reduce converts an array into a single value.
const nums = [1, 2, 3];
const sum = nums.reduce((total, current) => total + current, 0);
console.log(sum); // 6

6. Browser, DOM, Storage, Events

Q: What is DOM?

DOM stands for Document Object Model. It represents HTML page as a tree of objects. JavaScript can use DOM to read, update, add, or remove elements from the page. 
document.getElementById("title").innerText = "Hello";

Q: What is event bubbling?

Event bubbling means when an event happens on a child element, it propagates upward to its parent elements. We can stop it using event.stopPropagation().

Q: What is event delegation?

Event delegation means attaching one event listener to a parent instead of attaching listeners to multiple child elements. It improves performance and works well for dynamically added elements. 
document.getElementById("list").addEventListener("click", function (event) {
  if (event.target.tagName === "LI") {
    console.log("Clicked:", event.target.textContent);
  }
});

Q: localStorage vs sessionStorage?

localStorage stores data without expiry until manually cleared. sessionStorage stores data only for the browser tab session. Sensitive tokens should be handled carefully because browser storage can be risky if XSS happens. 
localStorage.setItem("name", "Neelesh");
sessionStorage.setItem("token", "abc");

Q: What is JSON?

JSON stands for JavaScript Object Notation. It is a lightweight format used to exchange data between frontend and backend. 
const user = { name: "Neelesh", role: "Admin" };
const jsonString = JSON.stringify(user);
const obj = JSON.parse(jsonString);

Q: Shallow copy vs deep copy?

Shallow copy copies only first level. Nested objects still share reference. Deep copy copies all levels completely. 
const user = { name: "Neelesh", address: { city: "Delhi" } };
const shallow = { ...user };
shallow.address.city = "Mumbai";
console.log(user.address.city); // Mumbai

Q: What is debounce?

Debounce delays function execution until user stops triggering the event for a specific time. It is useful in search boxes to avoid API call on every key press.

Q: What is throttle?

Throttle ensures a function runs at most once in a fixed time interval. It is useful for scroll or resize events.

7. Angular Client Questions

Q: What is component?

Component is responsible for a specific UI part. In my project, I created components for report list, report viewer, admin screens, and user mapping.

Q: What is service?

Service contains reusable logic and API call logic. I used services to call .NET Core APIs for reports, users, roles, and assignments.

Q: What is HTTP interceptor?

HTTP interceptor intercepts outgoing HTTP requests and incoming responses. In my project, I used it to attach bearer token in every API request and to handle common errors like 401, 403, and 500 globally.

Q: What is Auth Guard?

Auth Guard protects routes. It checks whether user is authenticated and authorized before opening a route. If user is not allowed, we redirect to login or unauthorized page.

8. 401/403 Error Handling

Q: Difference between 401 and 403?

401 means user is not authenticated or token is missing, invalid, or expired. 403 means user is authenticated but does not have required permission.

Q: How do you handle 401/403 in Angular?

In our application, we handled 401 and 403 errors through Angular HTTP interceptor and backend authorization checks. 401 means token is missing, invalid, or expired, so we redirect user to login or trigger token refresh using MSAL. 403 means user is authenticated but not authorized, so we show access denied message or redirect to an unauthorized page.

UI-level access control is only for user experience. Actual authorization is always enforced at API level. 
intercept(req, next) {
  const token = this.authService.getToken();

  const authReq = req.clone({
    setHeaders: {
      Authorization: `Bearer ${token}`
    }
  });

  return next.handle(authReq).pipe(
    catchError((error) => {
      if (error.status === 401) {
        this.authService.loginRedirect();
      }

      if (error.status === 403) {
        this.router.navigate(['/access-denied']);
      }

      return throwError(() => error);
    })
  );
}

Q: Reporting Hub context me 401/403 kaise handle kiya?

In Reporting Hub, if access token is missing, expired, or invalid, backend returns 401 and Angular interceptor redirects user to login or refreshes token using MSAL. If user is authenticated but tries to access a report or admin feature which is not assigned to him, backend returns 403. UI shows access denied or hides restricted menus/routes, but final security is enforced at API level.
