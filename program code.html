How to Explain Any Program to Client or Interviewer

  1. Understand the requirement: First explain what problem we are solving.
  2. Explain input and output: Tell what data we receive and what result we need to return.
  3. Explain the logic: Explain the main approach in simple words before writing code.
  4. Dry run with example: Take one sample input and explain step by step how output is generated.
  5. Write clean code: Use meaningful variable names and simple conditions/loops.
  6. Discuss edge cases: Explain how code behaves for empty input, null, duplicates, single item, etc.
  7. Mention complexity: Explain time complexity and space complexity in simple language.
  8. Final summary: End by saying why this solution works and why it is efficient.

Generic explanation line: “First, I will understand the input and expected output. Then I will apply a simple logic, dry run it with an example, handle edge cases, and finally explain the time and space complexity.”

Section 1: Practice Questions, Solutions, Input/Output & Logic

1. Palindrome Check String

Problem: Check whether a string reads the same forward and backward.

Input: "madam"

Output: true

Another Input: "hello"

Output: false

bool IsPalindrome(string str)
{
    int left = 0;
    int right = str.Length - 1;

    while (left < right)
    {
        if (str[left] != str[right])
            return false;

        left++;
        right--;
    }

    return true;
}

Logic:

  • Take one pointer at the start of the string.
  • Take another pointer at the end of the string.
  • Compare both characters.
  • If characters are not equal, return false.
  • If all characters match, return true.

How to explain to client/interviewer:

“Here we need to check if the string is the same from both sides. I am using two pointers, one from the beginning and one from the end. I compare both characters and move both pointers toward the center. If any mismatch is found, the string is not palindrome. Otherwise, it is palindrome.”

Time Complexity: O(n)

Space Complexity: O(1)

Two pointers String traversal Symmetry check

2. Move Zeros to Right

Problem: Move all zeros to the end while maintaining the order of non-zero elements.

Input: [1, 0, 2, 0, 3]

Output: [1, 2, 3, 0, 0]

void MoveZeros(int[] arr)
{
    int index = 0;

    for (int i = 0; i < arr.Length; i++)
    {
        if (arr[i] != 0)
        {
            arr[index] = arr[i];
            index++;
        }
    }

    while (index < arr.Length)
    {
        arr[index] = 0;
        index++;
    }
}

Logic:

  • Create an index variable starting from 0.
  • Loop through the array.
  • Whenever a non-zero element is found, place it at index position.
  • Increase index after placing non-zero value.
  • After all non-zero values are placed, fill the remaining positions with zero.

How to explain to client/interviewer:

“We are keeping all non-zero numbers in the same order and shifting them to the left side. After that, the remaining positions are filled with zero. This avoids using an extra array and modifies the same array.”

Time Complexity: O(n)

Space Complexity: O(1)

Stable order In-place Array traversal

3. Sort Array Without Extra Array

Problem: Sort an array in ascending order without using extra array.

Input: [5, 2, 8, 1]

Output: [1, 2, 5, 8]

void BubbleSort(int[] arr)
{
    for (int i = 0; i < arr.Length - 1; i++)
    {
        for (int j = 0; j < arr.Length - i - 1; j++)
        {
            if (arr[j] > arr[j + 1])
            {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}

Logic:

  • Compare two adjacent elements.
  • If the left element is greater than the right element, swap them.
  • After every pass, the largest element moves to the end.
  • Repeat until the array is sorted.

How to explain to client/interviewer:

“I am using bubble sort here. In this approach, we compare adjacent values and swap them if they are in the wrong order. After each pass, the largest value reaches its correct position at the end.”

Time Complexity: O(n²)

Space Complexity: O(1)

Bubble sort In-place sorting Swapping

4. Reverse a String Without Built-in Reverse

Problem: Reverse a string manually.

Input: "hello"

Output: "olleh"

string Reverse(string input)
{
    char[] arr = input.ToCharArray();

    int left = 0;
    int right = arr.Length - 1;

    while (left < right)
    {
        char temp = arr[left];
        arr[left] = arr[right];
        arr[right] = temp;

        left++;
        right--;
    }

    return new string(arr);
}

Logic:

  • Convert string into character array.
  • Use two pointers: left and right.
  • Swap characters from both ends.
  • Move pointers toward the center.
  • Create a new string from the reversed character array.

How to explain to client/interviewer:

“To reverse the string, I convert it into a character array because strings are immutable. Then I swap first and last characters, second and second-last characters, and continue until the middle.”

Time Complexity: O(n)

Space Complexity: O(n)

Two pointers Character array Manual reverse

5. Find Missing Number from 1 to N

Problem: Find the missing number from an array containing numbers from 1 to N.

Input: arr = [1, 2, 4, 5], n = 5

Output: 3

int FindMissing(int[] arr, int n)
{
    int expected = n * (n + 1) / 2;
    int actual = arr.Sum();

    return expected - actual;
}

Logic:

  • Calculate expected sum from 1 to N using formula n * (n + 1) / 2.
  • Calculate actual sum of array elements.
  • Missing number = expected sum - actual sum.

How to explain to client/interviewer:

“We know the sum of numbers from 1 to N using a mathematical formula. I calculate the expected total and subtract the actual total of array. The difference gives the missing number.”

Time Complexity: O(n)

Space Complexity: O(1)

Math formula Array sum Optimization

6. Remove Duplicates from Sorted Array

Problem: Remove duplicate elements from a sorted array.

Input: [1, 1, 2, 2, 3]

Output: [1, 2, 3]

Returned Length: 3

int RemoveDuplicates(int[] arr)
{
    int index = 1;

    for (int i = 1; i < arr.Length; i++)
    {
        if (arr[i] != arr[i - 1])
        {
            arr[index] = arr[i];
            index++;
        }
    }

    return index;
}

Logic:

  • Because the array is sorted, duplicate values are next to each other.
  • Start index from 1.
  • Compare current element with previous element.
  • If different, copy it to index position.
  • Return index as count of unique elements.

How to explain to client/interviewer:

“Since the array is already sorted, duplicates will be adjacent. I compare each element with the previous one. If it is different, I keep it as a unique value and move it forward in the same array.”

Time Complexity: O(n)

Space Complexity: O(1)

Sorted array Two pointers In-place update

7. Count Frequency of Characters

Problem: Count how many times each character appears in a string.

Input: "apple"

Output: a = 1, p = 2, l = 1, e = 1

Dictionary<char, int> CountFrequency(string str)
{
    var dict = new Dictionary<char, int>();

    foreach (char c in str)
    {
        if (dict.ContainsKey(c))
            dict[c]++;
        else
            dict[c] = 1;
    }

    return dict;
}

Logic:

  • Create a dictionary to store character and count.
  • Loop through every character in the string.
  • If character already exists in dictionary, increase count.
  • If character does not exist, add it with count 1.

How to explain to client/interviewer:

“I am using a dictionary where key is the character and value is its count. While reading each character, I either add it for the first time or increase its existing count.”

Time Complexity: O(n)

Space Complexity: O(k), where k is number of unique characters

Dictionary Hashing Frequency count

8. Check Anagram

Problem: Check whether two strings contain same characters with same frequency.

Input: s1 = "listen", s2 = "silent"

Output: true

Another Input: s1 = "hello", s2 = "world"

Output: false

bool IsAnagram(string s1, string s2)
{
    if (s1.Length != s2.Length)
        return false;

    int[] count = new int[256];

    foreach (char c in s1)
        count[c]++;

    foreach (char c in s2)
    {
        count[c]--;

        if (count[c] < 0)
            return false;
    }

    return true;
}

Logic:

  • If lengths are different, strings cannot be anagram.
  • Create a count array for characters.
  • Increase count for characters of first string.
  • Decrease count for characters of second string.
  • If any count becomes negative, return false.
  • If all counts balance, return true.

How to explain to client/interviewer:

“Two strings are anagrams when both have the same characters with the same frequency. I first count characters from the first string, then reduce the count using the second string. If counts are balanced, both strings are anagrams.”

Time Complexity: O(n)

Space Complexity: O(1), because fixed size array is used

Anagram Character count Hashing

9. Find Second Largest Element

Problem: Find the second largest distinct element from an array.

Input: [10, 5, 20, 8]

Output: 10

int SecondLargest(int[] arr)
{
    int first = int.MinValue;
    int second = int.MinValue;

    foreach (int num in arr)
    {
        if (num > first)
        {
            second = first;
            first = num;
        }
        else if (num > second && num != first)
        {
            second = num;
        }
    }

    return second;
}

Logic:

  • Keep two variables: first and second.
  • first stores the largest number.
  • second stores the second largest number.
  • If current number is greater than first, update both first and second.
  • If current number is between first and second, update second.

How to explain to client/interviewer:

“Instead of sorting the array, I scan it once and keep track of the largest and second largest numbers. This gives the answer in one pass.”

Time Complexity: O(n)

Space Complexity: O(1)

Single pass Optimization Largest tracking

10. Reverse Words in a Sentence

Problem: Reverse the order of words in a sentence.

Input: "I love CSharp"

Output: "CSharp love I"

string ReverseWords(string input)
{
    string[] words = input.Split(' ');

    Array.Reverse(words);

    return string.Join(" ", words);
}

Logic:

  • Split the sentence into words using space.
  • Reverse the words array.
  • Join the reversed words again with space.

How to explain to client/interviewer:

“Here we do not reverse each character. We reverse the order of words. First I split the sentence into words, then reverse the word array, and finally join them back into a sentence.”

Time Complexity: O(n)

Space Complexity: O(n)

String split Array reverse Join words

Important Edge Cases to Mention

  • Null input: What should happen if input is null?
  • Empty input: Example empty string or empty array.
  • Single element: Example array with only one item.
  • Duplicate values: Important for second largest and remove duplicates.
  • Case sensitivity: Example "Madam" and "madam" in palindrome.
  • Special characters: Example spaces, commas, symbols in string problems.

Final Interview Tip

Do not directly start coding. First explain your understanding, then explain logic, then write code, then test with input/output.

Best line to say: “I will first explain the logic, then dry run with an example, and after that I will write the code.”

Focus on clarity, not cleverness.
